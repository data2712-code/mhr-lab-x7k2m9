API Data Kartu Marvel Hero Rush

Versi 1 · data bahasa Indonesia · baca saja (read-only) · gratis

MHR Deck Lab menyediakan data kartu Marvel Hero Rush dalam format JSON dan CSV untuk toko kartu (LGS) dan proyek komunitas, misalnya katalog toko yang menjual kartu single per versi rarity. Data yang sama dipakai di situs ini: nama dan teks efek resmi Marvel Hero Rush Indonesia, statistik, trait, dan gambar printing Indonesia.

API ini berupa berkas statis. Tidak perlu API key dan tidak ada batas permintaan khusus, tapi mohon unduh/cache datanya di sisi Anda (lihat Cara memakai), jangan mengambilnya di setiap kunjungan halaman.

Endpoint

GEThttps://mhrdecklab.com/api/v1/cards.jsonsemua versi kartu (JSON)
GEThttps://mhrdecklab.com/api/v1/cards.csvisi yang sama, untuk impor lewat spreadsheet (UTF-8)
GEThttps://mhrdecklab.com/api/v1/sets.jsondaftar set yang sudah rilis + jumlah kartu dan versi

Isinya hanya set yang sudah rilis. Kartu spoiler/pratinjau yang belum rilis tidak dimasukkan. Data akun, deck, koleksi, dan komentar pengguna situs tidak pernah ada di API ini.

Struktur data

cards.json berisi metadata di bagian atas lalu daftar cards. Satu baris = satu versi cetak: kartu yang punya beberapa rarity (mis. UR, MR, SEC, HR) muncul sebagai beberapa baris, masing-masing dengan gambar sendiri — cocok dijadikan produk terpisah di toko.

KolomIsi
idID unik versi = <card_no>-<variant>. Stabil — aman dipakai sebagai SKU. Tidak akan berubah selama API v1.
card_noNomor kartu, mis. BP01-001. Semua versi rarity dari satu kartu punya card_no yang sama.
setKode set (= awalan nomor): BP01, SP01, SD01–SD04, PB01, EB01, TB01.
typekarakter atau rush_point. Rush Point tidak punya nama, warna, statistik, dan efek.
rarityRarity dasar: R, SR, GR, UR, MR, SEC, HR, PR, ER, TR, C.
variantKode versi. Biasanya sama dengan rarity; beberapa kartu punya dua versi dengan rarity sama dan diberi akhiran: HR_616, ER_CHAMPION, TR_SILVER, TR_FULLART.
variant_labelLabel siap tampil, mis. HR /99, HR /616, ER Top 4, ER Champion, TR Gold.
is_maintrue untuk versi utama (versi standar) kartu itu.
nameNama kartu bahasa Indonesia, mis. [Antimatter] Iron Man.
colorMerah, Biru, Hijau, Kuning (kosong untuk Rush Point).
level, range, powerLv, jarak serangan (R), dan Power. null untuk Rush Point.
traitsTrait dipisah garis miring, mis. Human/Avengers.
effectTeks efek bahasa Indonesia.
errataVersi errata resmi terakhir (mis. V.1, V.2), null kalau tidak pernah errata. Teks di API sudah versi setelah errata.
fan_translationtrue kalau teks Indonesia kartu itu masih terjemahan komunitas (belum teks resmi).
indonesian_printKhusus Rush Point: true kalau ada di daftar resmi versi Indonesia, false kalau baru ada di versi Inggris.
imageURL gambar kartu versi itu (printing Indonesia bila ada; ber-watermark SAMPLE).
urlHalaman kartu di MHR Deck Lab.

Cara memakai

  1. Ambil cards.json (atau cards.csv) dan simpan di database/katalog Anda. Gunakan id sebagai kunci produk.
  2. Cek pembaruan secara berkala, misalnya sehari sekali atau saat ada pengumuman set baru: kalau data_hash berbeda dari yang Anda simpan, impor ulang. Data biasanya hanya berubah saat set baru rilis atau ada errata.
  3. Harga, stok, kondisi kartu, dan transaksi sepenuhnya dikelola di sistem Anda — API ini tidak memuat dan tidak menerima data tersebut.
  4. Untuk gambar, sebaiknya simpan salinan di server/CDN Anda sendiri (atau lewat optimizer gambar framework Anda), jangan memuat langsung dari mhrdecklab.com di setiap kunjungan.

Contoh (Next.js, server-side, diperbarui maksimal sehari sekali):

const res = await fetch('https://mhrdecklab.com/api/v1/cards.json', { next: { revalidate: 86400 } });
const { cards, data_hash } = await res.json();
const karakter = cards.filter(c => c.type === 'karakter');
const singlesSP01 = karakter.filter(c => c.set === 'SP01');   // satu item per versi rarity

Setelah data di situs ini diperbarui, file API bisa butuh beberapa jam sampai versi terbaru terbaca dari cache Cloudflare.

  1. Atribusi wajib. Tampilkan teks "Data kartu: MHR Deck Lab" dengan tautan ke mhrdecklab.com di halaman yang memakai data ini (cukup di footer atau halaman katalog).
  2. Hak cipta tetap milik pemiliknya. Marvel Hero Rush, gambar kartu, dan karakternya © MARVEL © JASON. Teks kartu resmi berasal dari Marvel Hero Rush Indonesia. MHR Deck Lab adalah situs komunitas tidak resmi; jangan menyebut data ini sebagai data resmi.
  3. Boleh ditampilkan, tidak boleh dijual ulang sebagai dataset. Data boleh dipakai untuk menampilkan katalog, kartu, dan deck di situs/aplikasi Anda, tetapi tidak boleh dijual, disewakan, atau dibagikan ulang sebagai kumpulan data.
  4. Tanpa jaminan. API disediakan apa adanya, tanpa jaminan ketersediaan atau ketepatan. Selalu cocokkan kartu fisik saat jual-beli.
  5. Perubahan format. Format v1 dijaga stabil. Perubahan yang tidak kompatibel akan dirilis sebagai versi baru (/api/v2/) dan diumumkan lebih dulu.
  6. MHR Deck Lab dapat menghentikan akses atau API ini bila terjadi penyalahgunaan.
