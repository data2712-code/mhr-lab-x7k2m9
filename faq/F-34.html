F-34 · "Becomes X" vs "+X / -X": which one wins?

A change ("R changes to 3", "Lv changes to 6") replaces earlier increases and decreases. An increase or decrease that comes after the change is applied on top of the new value. If two changes apply, the later one wins; if the later one ends, the earlier one applies again. The detailed cases are in CR 301.41.

Examples:

  • BP01-097 「Original Mutant」 Namor is in your BATTLE: the R of your Character in FRONT changes to 3. If that Character then gets R+1 (for example from BP01-117 「Ancestral Blessing」 New Black Panther), its R is 4: the +1 is added on top of the change.
  • SD04-001 「God of Trick」 Loki is attached to a Character: its R changes to 0 and it gets Power+1000. Any R+X that Character had before is gone. The Power+1000 is an increase, so it is added normally.
  • That Character's controller has Namor in BATTLE and the Character is in FRONT. Two changes now apply: Loki's (R becomes 0) and Namor's (R becomes 3). The one that started applying later wins. If Loki was attached after Namor was already there, the R is 0; if Namor arrives later, the R is 3, and if Namor then leaves, Loki's change applies again (R 0).
Source: CR 301.41.a–k (especially 301.41.d and 301.41.f). Head Judge of Marvel Hero Rush Indonesia, 26 Aug and 24 Sep 2026.
